# The House of Coffee — Jaipur

> **Specialty Micro-Roastery & Book Lounge** • Vaishali Nagar & C-Scheme, Jaipur.

An ultra-premium, bespoke single-page web experience for **The House of Coffee** in Jaipur, crafted in a **Warm Brutalist Roastery & Kinfolk Editorial** aesthetic with Swiss hairline grids and high-contrast typography.

---

## ☕ Key Features

- **Live Outlet Switcher**: Seamlessly toggle between **Vaishali Nagar** (Flagship Amber Library & Games) and **C-Scheme** (Sunlit Tree-Canopy Balcony). Dynamically synchronizes active addresses, live crowd status, Google Maps location, and 1-click WhatsApp ordering.
- **Full-Width Architectural Swiss Grid Hero**: Editorial headline paired with a technical roast ticker and a 21:9 split-frame gallery strip featuring authentic cafe photography.
- **Numbered Editorial Lookbook**:
  - `01 / THE AMBER LIBRARY & BOARD-GAME SHELF` (Backlit 2700K floor-to-ceiling shelves with Sequence, Catan, and books)
  - `02 / PÂTISSERIE COUNTER & WORK TABLES` (Solid teakwood focus desks, power outlets, daily fresh bakes)
  - `03 / BALCONY COLD BREW DECK` (Open-air tree-canopied patio with cascading iced coffee)
- **Roaster's Tasting Menu & Bean Bar**: Filter by *Espresso & Latte Art*, *Iced Matcha & Cold Brews*, *Artisanal Bakes & Toast*, and *Whole Beans & Brew Gear*.
- **Interactive Contactless Table QR Simulator**: Simulates what guests experience when scanning the brass QR stands placed on cafe tables.
- **Order Ahead & Table Booking Modal**: Tactile multi-step reservation flow with instant ticket generation, celebratory confetti, and WhatsApp forwarding.
- **Split-Screen Outlet Directory & Dynamic Maps**: Interactive comparison cards with driving directions, direct outlet calling, and WhatsApp ordering.

---

## 🛠 Tech Stack

- **Framework**: React 18
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS v4 with custom tokens
- **Typography**: Instrument Serif, Syne, JetBrains Mono, Plus Jakarta Sans
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **Testing & Verification**: Playwright

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
